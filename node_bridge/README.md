Node bridge for Gladiator Arena.

Purpose
- Exposes a local HTTP API used by the SFML game and local demo tools.
- Talks to the deployed contract suite generated by `blockchain/scripts/deploy.js`.

Setup
1. Copy `.env.example` to `.env`.
2. Install dependencies with `npm install`.
3. Deploy the contracts from the `blockchain/` folder. This writes `node_bridge/contracts.generated.json`.
4. Start the bridge with `npm start`.

Important
- The marketplace endpoints accept raw private keys. That is only for local development on a private chain. It is not appropriate for production or a public deployment.
- The `/mintNFT` endpoint is the one used by the current SFML game client after a match ends.

Main endpoints
- `GET /health`
- `GET /contracts`
- `POST /mintNFT`
- `POST /characters/mint`
- `POST /characters/upgrade`
- `POST /weapons/mint`
- `POST /marketplace/list-character`
- `POST /marketplace/list-weapon`
- `POST /marketplace/buy`
